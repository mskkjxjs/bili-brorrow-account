# 借用B站账号

一个用于 Chrome / Edge 的 Manifest V3 扩展：使用小号完成番剧主文档、播放器初始化和取流，同时让观看进度、观看历史、点赞、评论和消息继续使用浏览器当前登录的大号。

支持普通视频和番剧，并可自动选择播放器提供的最高画质。

## 功能

- **账号分离**：仅番剧主文档、播放器初始化及播放地址请求使用小号 SESSDATA。
- **大号记录**：不接管观看历史或其他账号操作，无需提供大号 Cookie。
- **自动最高画质**：选择画质菜单中的最高可用项，并尝试启用杜比或 Hi-Res 音质。
- **页面切换检测**：B 站站内跳转至其他视频后重新检测画质。
- **自动续期**：每日检查 Cookie 状态，需要时轮换 SESSDATA、bili_jct 和刷新令牌。
- **独立开关**：小号取流、自动最高画质与自动续期可分别启用。
- **本地配置**：账号凭证和设置仅保存在扩展的 `chrome.storage.local` 中。

## 安装

1. 下载 [最新 Release](https://github.com/mskkjxjs/bili-brorrow-account/releases/latest) 中的 ZIP 文件并解压。
2. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的目录。
5. 打开扩展设置，填写小号 SESSDATA，按需开启功能并保存。
6. 刷新已经打开的视频页面。

要求 Chrome 或 Edge 128 及更高版本。

## 使用方法

### 小号初始化并取流

在扩展设置中只填写 **SESSDATA 的值**，不要包含 `SESSDATA=`、其他 Cookie 名称或分号，然后启用“小号初始化并取流”。

扩展仅向以下 B 站请求应用小号凭证：

- 普通视频及番剧的播放地址请求。
- 播放器 `v2` 初始化请求。
- 番剧主文档请求，用于让服务器生成小号的 SSR 播放数据。

番剧观看进度通过大号历史记录单独恢复。

请使用自己有权使用的账号。SESSDATA 等同于登录凭证，不要分享或提交到仓库。

### 自动续期 SESSDATA

自动续期需要同时填写 **SESSDATA**、**bili_jct** 和 **ac_time_value**。其中 `ac_time_value` 是登录时生成的持久化刷新令牌，可从对应账号浏览器的 `localStorage` 中获取，不是 Cookie。

这两项仅在开启自动续期时必填，不启用续期时可留空。获取 `ac_time_value` 时，需使用扫码登录且不能选择一次性登录，然后在对应账号的浏览器控制台输入 `window.localStorage.ac_time_value`。

开启“每日检查并自动续期 SESSDATA”后，扩展会在浏览器启动、保存设置及每日定时任务中检查状态。仅在 B 站返回需要刷新时执行完整轮换，并保存响应中的新 SESSDATA、新 bili_jct 和新刷新令牌。

续期请求使用 `credentials: "omit"`，不读取浏览器 Cookie，也不让刷新响应写入浏览器 Cookie，因此不会覆盖大号登录状态。扩展仅通过 `webRequest` 读取自己发起的刷新响应。

### 自动切换最高画质

开启“自动切换最高画质”后，扩展会在普通视频和番剧页面选择画质菜单的第一项，即播放器列出的最高可用画质。实际可选画质仍取决于视频、账号权限和 B 站返回结果。

该功能不需要填写 SESSDATA，可独立于小号取流使用；不包含直播画质切换，也不会显示切换成功提示。设置变更后，已打开的视频页会应用新开关状态。

## 隐私与权限

- `storage`：保存账号凭证和功能开关。
- `alarms`：每日检查是否需要续期。
- `webRequest`：仅读取扩展自己发起的续期响应中的新 Cookie。
- `declarativeNetRequestWithHostAccess`：仅对指定番剧主文档、播放器及续期请求修改 Cookie 请求头。
- `www.bilibili.com`、`api.bilibili.com` 与 `passport.bilibili.com` 主机权限：识别视频页、处理播放器请求及完成凭证续期。

扩展不会读取或修改浏览器保存的大号 Cookie，也不包含远程配置、分析统计或广告代码。

## 已知限制

- 自动续期依赖有效的 `ac_time_value`，无法恢复已经失效或未提供刷新令牌的登录状态。

## 更新说明

### 1.0.1

- 修复无法继续观看番剧的问题，从大号历史记录恢复当前剧集的观看进度。

### 1.0.0

- 支持使用具有相应权限的小号观看大会员专享番剧，观看历史及其他账号操作仍使用大号。
- 番剧主文档使用小号生成 SSR 播放数据，并处理播放数据中的前端会员限制标记。
- 支持 `__playinfo__`、`playurlSSRData`、Next.js 缓存以及 XHR 和 fetch 播放响应。
- 新增番剧站内换集处理和会员播放器弹层处理。
- 新增独立设置桥，确保 MAIN world 播放脚本正确响应功能开关。

### 0.1.3

- 新增 SESSDATA 自动续期，按需轮换 SESSDATA、bili_jct 和刷新令牌。
- 新增每日检查、浏览器启动检查和保存设置时立即检查。
- bili_jct 和 ac_time_value 标记为可选，仅在启用自动续期时必填。
- 插件内补充 ac_time_value 的控制台获取方法及扫码登录注意事项。
- 续期请求与浏览器 Cookie 隔离，避免覆盖大号登录状态。
- 已知问题：当前版本暂不支持观看大会员专享内容（番剧、电影等）。

### 0.1.2

- 新增普通视频和番剧的自动最高画质功能。
- 支持播放器加载重试、站内页面切换检测及杜比 / Hi-Res 音质增强。
- 设置页新增“自动切换最高画质”独立开关，默认开启。
- 自动画质功能支持不配置小号时单独使用。
- Release 打包流程已包含自动画质脚本。

自动画质逻辑参考 Benjia Zou 的“B站自动最高画质”用户脚本，移除了直播及通知部分。

## 构建与发布

仓库通过 `.github/workflows/release.yml` 自动打包。推送与 `manifest.json` 版本一致的 `x.y.z` 标签后，GitHub Actions 会校验版本、生成扩展 ZIP 并创建 Release。
