# 借用B站账号

一个用于 Chrome / Edge 的 Manifest V3 扩展：使用小号完成播放器初始化和取流，同时让视频主页面、观看历史、点赞、评论和消息继续使用浏览器当前登录的大号。

支持普通视频和番剧，并可自动选择播放器提供的最高画质。

## 功能

- **账号分离**：仅播放器初始化及播放地址请求使用小号 SESSDATA。
- **大号记录**：不接管视频主页面、观看历史或其他账号操作，无需提供大号 Cookie。
- **自动最高画质**：选择画质菜单中的最高可用项，并尝试启用杜比或 Hi-Res 音质。
- **页面切换检测**：B 站站内跳转至其他视频后重新检测画质。
- **独立开关**：小号取流与自动最高画质可分别启用，自动画质默认开启。
- **本地配置**：SESSDATA 和设置仅保存在扩展的 `chrome.storage.local` 中。

## 安装

1. 下载 [最新 Release](https://github.com/mskkjxjs/bili-brorrow-account/releases/latest) 中的 ZIP 文件并解压。
2. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的目录。
5. 打开扩展设置，填写小号 SESSDATA，按需开启功能并保存。
6. 刷新已经打开的视频页面。

要求 Chrome 或 Edge 128 及更高版本。

## 使用方法

### 小号初始化并取流

在扩展设置中只填写 **SESSDATA 的值**，不要包含 `SESSDATA=`、其他 Cookie 名称或分号，然后启用“小号初始化并取流”。

扩展仅向以下 B 站接口应用小号凭证：

- 普通视频及番剧的播放地址请求。
- 播放器 `v2` 初始化请求。

请使用自己有权使用的账号。SESSDATA 等同于登录凭证，不要分享或提交到仓库；扩展不会自动续期，失效后需要手动更新。

### 自动切换最高画质

开启“自动切换最高画质”后，扩展会在普通视频和番剧页面选择画质菜单的第一项，即播放器列出的最高可用画质。实际可选画质仍取决于视频、账号权限和 B 站返回结果。

该功能不需要填写 SESSDATA，可独立于小号取流使用；不包含直播画质切换，也不会显示切换成功提示。设置变更后，已打开的视频页会应用新开关状态。

## 隐私与权限

- `storage`：保存 SESSDATA 和功能开关。
- `declarativeNetRequestWithHostAccess`：仅对指定播放器接口修改 Cookie 请求头。
- `www.bilibili.com` 与 `api.bilibili.com` 主机权限：识别视频页并处理播放器请求。

扩展不会读取或修改浏览器保存的大号 Cookie，也不包含远程配置、分析统计或广告代码。

仓库通过 `.github/workflows/release.yml` 自动打包。推送与 `manifest.json` 版本一致的 `x.y.z` 标签后，GitHub Actions 会校验版本、生成扩展 ZIP 并创建 Release。
